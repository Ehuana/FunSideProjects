## What is this?

An interactive single-page guide covering the EV Mode button mod for the 2004–2009 Toyota Prius (Gen 2). The US-spec cars have the hardware built in — Toyota just never wired up the button. This page documents the wiring, install steps, and translated Japanese manual instructions.

## Why?

Honestly just a fun weekend thing. I like cars, I like tinkering with web stuff in my free time, and I had this relic of an HTML page sitting around from like 2008. Figured I'd see how far I could take it with modern tooling while keeping it dead simple — no frameworks, no build step, just files you can open in a browser.

## Stack

| Tech | Role |
|------|------|
| HTML5 | Structure |
| Tailwind CSS (CDN) | Utility classes |
| Vanilla CSS | Glassmorphism, animations, custom components |
| Vanilla JS | Gallery, lightbox, accordion, scroll effects |

Zero dependencies. No `node_modules`. No build pipeline. Just vibes.

## Features

- 🪟 Apple-inspired glass UI with frosted card effects
- 🎨 Animated gradient background orbs
- 🖼️ Click-to-enlarge image gallery with lightbox
- 📱 Fully responsive + mobile nav
- 🎛️ Accordion FAQ from the translated JDM owner's manual
- 📊 Scroll progress bar + fade-in animations
- 🔝 Back-to-top button

## Running it

```
Just open index.html in your browser. That's it.
```
